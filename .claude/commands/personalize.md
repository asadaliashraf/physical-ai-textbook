# /personalize

Personalize chapter content for a specific learner level.

## Usage
```
/personalize [chapter-path] [level: beginner|intermediate|advanced]
```

## What This Does
Rewrites the chapter with:
- Appropriate technical depth for the level
- Extra explanations for beginners
- Advanced optimizations for experts
- Relevant analogies and examples
- Level-appropriate exercises

## Example
```
/personalize docs/module-1/week1-2/chapter-1-1.md beginner
```
