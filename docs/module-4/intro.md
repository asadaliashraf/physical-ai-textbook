# Module 4: Vision-Language-Action (VLA)

## The Convergence of Language and Robotics

VLA models bridge three modalities:
- **Vision**: Understanding the visual environment
- **Language**: Processing natural language instructions
- **Action**: Executing physical motor commands

## Real-World Example

```
Human: "Pick up the red cup and put it in the sink"

VLA System:
1. Vision: Identifies red cup location (x=0.3, y=0.1, z=0.8)
2. Language: Understands "pick up", "red cup", "sink"
3. Planning: Generates action sequence
4. Action: Executes via ROS 2
```
