# Appendix A: Hardware Requirements

## Workstation Requirements

| Component | Minimum | Recommended |
|-----------|---------|-------------|
| **GPU** | RTX 3070 8GB | RTX 4090 24GB |
| **CPU** | Intel i7-12th gen | AMD Ryzen 9 7950X |
| **RAM** | 32 GB | 64 GB DDR5 |
| **Storage** | 256 GB NVMe | 1 TB NVMe |
| **OS** | Ubuntu 22.04 | Ubuntu 22.04 |

- **NVIDIA Jetson Orin Nano 8GB** (~$500) - Great for students
- **NVIDIA Jetson Orin NX 16GB** (~$800) - Advanced projects
