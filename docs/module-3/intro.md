# Module 3: The AI-Robot Brain (NVIDIA Isaac™)

## Introduction

NVIDIA Isaac is the most powerful AI platform for robotics. It combines photorealistic simulation, hardware-accelerated inference, and cutting-edge AI frameworks into a single unified platform.

## The Isaac Ecosystem

```
NVIDIA Isaac Platform
├── Isaac Sim          → Photorealistic simulation (Omniverse-based)
├── Isaac ROS          → Hardware-accelerated ROS 2 packages
│   ├── Isaac ROS Visual SLAM
│   ├── Isaac ROS DNN Image Segmentation
│   └── Isaac ROS Nvblox (3D scene reconstruction)
├── Isaac Lab          → Reinforcement learning framework
└── Isaac Perceptor    → Full-stack embodied AI
```

## Hardware Requirements

| Component | Minimum | Recommended |
|-----------|---------|-------------|
| **GPU** | RTX 3070 (8GB) | RTX 4090 (24GB) |
| **CPU** | Intel i7-12th gen | Intel i9 / AMD Ryzen 9 |
| **RAM** | 32 GB | 64 GB |
| **Storage** | 100 GB NVMe | 500 GB NVMe |
| **OS** | Ubuntu 22.04 | Ubuntu 22.04 |
